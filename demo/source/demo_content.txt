# 演示内容（内置样例教材）
#
# 为什么用这种朴素的竖线分隔格式，而不是 JSON：
#   渲染脚本是 Windows PowerShell 5.1 的。ConvertFrom-Json 产生的
#   PSCustomObject 在 5.1 里的属性访问有诡异的坑 —— $b.es 在表达式里能取到值、
#   在赋值/命令模式下却得到空，而且**不报任何错**，表现为整列文字凭空消失。
#   排查代价极高。改成纯字符串数组后，-split '|' 的结果是普通数组，
#   不涉及任何对象、属性、类型转换，行为完全可预期。
#
# 格式（每行一条，字段用 | 分隔，正文里不要出现 | ）：
#   PAGE|<页标题>            开始新的一页
#   H|<文字>|<字号>          大标题
#   S|<文字>|<字号>          小标题
#   R|                       水平分隔线
#   P|<文字>|<字号>          正文段落（自动换行）
#   Z|<文字>|<字号>          中文行
#   I|<文字>|<字号>          列表项
#   SP|                      垂直留白
#   V|<西语词>|<词性>|<释义>  词表三列
#
# 版权：正文取自塞万提斯《堂吉诃德》开篇（公版，1615 年），
#       词汇表与练习题为本项目自写，均无版权问题。
# ============================================================================
